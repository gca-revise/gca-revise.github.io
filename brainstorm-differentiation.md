# Brainstorm: how is this different from Quizlet?

Status: ideas only. Nothing here is agreed or built.

## The honest starting point
Plain word-and-definition revision is what Quizlet already does. This project is worth building only for what Quizlet can't or won't do. Also worth saying: building it is itself part of the teacher's learning plan.

## Reasons that already hold
- **Teacher control:** the teacher decides every rule (marking, when a word is retired, what the sets are).
- **No ads, no accounts, no paywall.** Quizlet's free tier limits some modes (check the current terms before relying on this).
- **School identity:** school crest and colours, plus a look for each set text.
- **Spelling matters:** typed answers must be spelled correctly, by design.

## Ideas that go beyond Quizlet (the real differentiators)
1. **Exam-skills layer for quotes** (strongest idea). Not just "finish the quote". Also: who said it, to whom, when; which theme does it show; which character does it link to; which technique is used. Builds the knowledge GCSE answers need.
2. **Words tied to the texts.** Each word links to the text it helps with (e.g. a word that appears in Macbeth), and shows the quote it comes from.
3. **Words in context.** "Which sentence uses *ephemeral* correctly?" Tests use, not just meaning.
4. **Spaced return.** A retired word comes back after a few days for a quick re-check, so learning sticks.
5. **Anonymous class-level insight** (later, needs a privacy and school-policy conversation). The teacher sees which words the whole class finds hardest, with no student names. Needs a server, so not before the web version works.
6. **Text-themed sets.** Macbeth, An Inspector Calls, Jekyll and Hyde, Frankenstein, Power and Conflict each get their own mood and colour. Calm, readable, not childish.
7. **Light rewards.** Per-text "mastered" badges and a daily goal. Keep it calm.

## Possible shortlist (for the teacher to choose)
- Must have: 1 (quote context), 2 (words tied to texts), 6 (text themes).
- Nice next: 3, 4.
- Later: 5, 7.

## Alternative worth keeping in mind
Put the plain vocab on Quizlet for quick use, and build only the parts Quizlet can't do.
